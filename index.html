FAQ

Questions? Answered.

What is Qripty?
▾
Qripty is a quantum readiness platform purpose-built for fintech. It discovers cryptographic algorithms in use across your API estate, generates a cryptographic bill of materials (CBOM), assesses risk, and deploys hybrid post-quantum protection — without application code changes or moving data outside your infrastructure.
Does it require code changes?
▾
No. Qripty deploys at the API gateway or network layer, entirely outside your application codebase. The entire cryptographic upgrade happens transparently in the infrastructure layer.
Does Qripty access our data or API payloads?
▾
Never. Qripty operates exclusively at the header and metadata level. Payload content is never accessed, inspected, or transmitted — enforced by architecture, not just policy.
How long does deployment take?
▾
Most organizations have Qripty deployed and generating their first cryptographic inventory within a single business day. Hybrid PQC protection activation typically follows in the same deployment window.
What compliance frameworks are supported?
▾
Qripty generates CBOM documentation in CycloneDX 1.6 format and pre-built reports for RBI IT Framework, SEBI Cybersecurity Circular, NIST SP 800-208, and ISO 27001.
